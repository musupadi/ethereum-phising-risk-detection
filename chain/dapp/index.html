RiskRegistry — Pembaca On-Chain DApp

Halaman ini membaca skor risiko langsung dari smart contract melalui JSON-RPC. Tidak ada FastAPI, tidak ada database, tidak ada backend di tengah.

Koneksi

Belum terhubung

Cek skor satu wallet — fungsi getRisk()

Riwayat penilaian — event RiskUpdated

Direkonstruksi dari log event sejak block 0. Mapping di Solidity tidak bisa di-iterate, sehingga daftar ini hanya mungkin dibaca lewat event log.

Yang dibuktikan halaman ini

alur lama : Browser → Streamlit → FastAPI → web3.py → Kontrak alur DApp : Browser ────────────────────────────────► Kontrak

Semua pemanggilan di halaman ini memakai eth_call dan eth_getLogs mentah via fetch() — ABI di-encode dan di-decode sendiri di JavaScript, tanpa satu pun library eksternal. Artinya lapisan pembacaan sistem ini sudah benar-benar tidak bergantung pada backend terpusat: siapa pun yang punya alamat kontrak dan akses ke node bisa memverifikasi skornya sendiri.
